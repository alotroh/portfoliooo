# TROHA — портфолио

Весь сайт целиком лежит в этой папке. Снаружи ему ничего не нужно.
→ Телеграм: [@ceoofmembers](https://t.me/ceoofmembers) · Инстаграм: [@trohantrohan](https://instagram.com/trohantrohan)

## Запуск

Из этой папки:

```bash
node serve.js
```

Откроется на `http://localhost:4500`. Порт можно поменять: `PORT=4600 node serve.js`.

Просто открыть `index.html` двойным кликом не получится — с `file://` браузер
не отдаёт видео и не запускает шейдер. Нужен любой локальный сервер.

## Что внутри

| Файл | Что делает |
| --- | --- |
| `index.html` | Разметка: ракорд, герой, полоса работ с телефоном, летающие карточки, блок о себе |
| `styles.css` | Токены, типографика, сетка, все состояния |
| `main.js` | Lenis + GSAP ScrollTrigger: вся хореография прокрутки |
| `ripple.js` | WebGL-шейдер: рябь по видео героя под курсором |
| `sound.js` | Звук: клик на карточках из `media/sfx`, через Web Audio |
| `serve.js` | Локальный сервер, раздаёт только эту папку |
| `media/` | Фоновые видео, скриншоты работ, `mobile/` с мобильными версиями и `sfx/` со звуками |

GSAP 3.13 и Lenis 1.1.18 подключены с CDN, локальных зависимостей нет,
сборка не нужна.

## Заявки из подбора

Подбор отправляет заявку в телеграм через серверную функцию `api/lead.js`.
Токен бота в коде страницы держать нельзя — кто его прочитал, тот получил
полный доступ к боту, — поэтому он живёт в переменных окружения.

На Vercel → Settings → Environment Variables:

| Переменная | Где взять |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | создать бота у [@BotFather](https://t.me/BotFather), он выдаст токен |
| `TELEGRAM_CHAT_ID` | свой id скажет [@userinfobot](https://t.me/userinfobot); боту нужно один раз написать `/start`, иначе он не сможет вам ответить |

После добавления переменных проект нужно передеплоить — старая сборка их не
увидит.

Пока переменных нет, форма работает, но заявка никуда не уходит: локальный
сервер пишет об этом в консоль, на проде вернётся ошибка.

## Где люди бросают подбор

Квиз живёт на одной странице и адрес не меняет, поэтому обычная аналитика
увидела бы один просмотр и ничего больше. Вместо неё подбор сам считает путь:
на каком вопросе человек остановился и сколько секунд просидел на каждом шаге.

Если человек начал отвечать и закрыл вкладку, не отправив заявку, в тот же
телеграм приходит сообщение «Подбор бросили» — **без звука**, чтобы не мешало.
В нём только шаг, вопрос и секунды: ни контактов, ни написанного текста, ни
файлов. Человек не нажимал «Отправить» — значит ничего из написанного им не
забираем. Это же делает сообщение обезличенным, и согласия для него не нужно.

Оговорка: отойти на соседнюю вкладку браузер показывает тем же событием, что
и закрытие. Иногда «ушёл» означает «отвлёкся и вернулся» — если потом придёт
заявка, значит человек дошёл.

Законченные заявки теперь тоже несут этот путь — видно, где человек завис.

Куки для этого не нужны, баннер согласия тоже: ничего, что привязано к
человеку, подбор не хранит.
