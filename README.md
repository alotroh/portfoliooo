# TROHA — портфолио

Одностраничный сайт-портфолио. Веб-дизайн и разработка.
→ Телеграм: [@ceoofmembers](https://t.me/ceoofmembers) · Инстаграм: [@trohantrohan](https://instagram.com/trohantrohan)

## Что внутри

Статика без сборки — открывается как есть.

| Файл | Что делает |
| --- | --- |
| `index.html` | Разметка всех секций: ракорд, герой, киноплёнка, карточки работ, блок о себе |
| `styles.css` | Токены, типографика, сетка, все состояния |
| `main.js` | Lenis + GSAP ScrollTrigger: закрепления, раскрытия, летающие карточки, прогресс-бар |
| `ripple.js` | WebGL-шейдер: рябь по видео героя под курсором |
| `media/` | Фоновые видео и скриншоты работ |

GSAP 3.13 и Lenis 1.1.18 подключены с CDN, локальных зависимостей нет.

## Запуск

Нужен любой локальный сервер — видео и шейдер не работают с `file://`:

```bash
npx serve .
```

## Деплой

Любой статический хостинг без настроек. На Vercel — импорт репозитория, framework preset «Other», корень проекта оставить как есть. На GitHub Pages — включить Pages из ветки `main`, папка `/ (root)`.
